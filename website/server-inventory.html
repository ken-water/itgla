Infrastructure inventory

Server inventory software for small teams

A server inventory gives you one dependable place to record which machines you use, how to reach them, and what work they support.

What belongs in a server inventory?

Start with the details you need during routine operations: an IP address, ports, tags, and a short name or note. Add structured fields such as cloud provider, region, operating system, project, environment, or owner when those facts help you search, filter, or hand work to someone else.

Use tags for flexible grouping

Tags work well for cross-cutting labels such as production, customer-a, nginx, or needs-review. Use a dedicated field when a value has one consistent meaning, such as cloud provider or operating system. ITGLA supports both, so you can begin simply and add custom columns as your inventory grows.

Keep the inventory maintainable

Use consistent names, agree on a small set of environment tags, avoid putting credentials in notes, and review records when a server is retired or reassigned. An inventory documents infrastructure; it is not a substitute for monitoring, access controls, backups, or a secrets manager.

A local-first option

ITGLA stores the workspace in a local SQLite database. The current desktop app does not require an account or cloud sync. You can import a spreadsheet, map its columns, search custom values, filter by tags, and copy individual cells.
