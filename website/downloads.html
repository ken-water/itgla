macOS verification steps

VERIFY YOUR DOWNLOAD

Check before you run.

Save the package and checksum file in the same folder. A matching hash confirms the file matches the published release; it does not replace code signing.

Download sha256sums
Windows · PowerShell

Calculate the hash of your downloaded EXE:

Get-FileHash .\itgla-v0.6.3-windows-x86_64-setup.exe -Algorithm SHA256

Compare it with the line for the same filename in sha256sums. Use the ZIP filename instead if you chose the portable archive.

Linux · Terminal
sha256sum --ignore-missing -c sha256sums

Run this in the download folder. Your downloaded package must report OK; files you did not download are skipped.

macOS · Terminal
shasum -a 256 itgla-v0.6.3-macos-arm64.dmg

Compare with the same filename in sha256sums. For Intel, replace arm64 with x86_64.
