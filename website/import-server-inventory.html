Import guide

Import a server inventory from Excel or CSV

Keep your existing spreadsheet. ITGLA lets you decide how each source column should become a server field.

Supported files and required columns

ITGLA accepts Excel, OpenDocument, CSV, and TSV files with a header row. Every import must map exactly one column to IP Address and one to Ports. Tags are optional; if you do not provide tags, imported records receive an imported tag.

You can start from the in-app CSV template, but it is optional. Existing spreadsheets do not need to use ITGLA's exact column names.

Map columns to tags or structured fields

Use Tags for flexible labels such as prod, database, or customer-a. Use structured fields for values you expect to compare consistently, such as Cloud Provider, Region, OS, Project, Environment, Owner, Service, or Domain. You can also map a column to an existing custom field, create a new field, or skip it.

Prepare a reliable spreadsheet

  • Use one header row and one server per row.
  • Keep IP addresses and ports in separate columns.
  • Separate multiple tags with commas.
  • Use consistent values for fields such as Environment and Cloud Provider.
  • Do not include passwords, private keys, access tokens, or other secrets.

Import stays on your device

The desktop app parses the selected file locally and stores records in its SQLite database. The current product does not upload your spreadsheet or server records to ITGLA.
