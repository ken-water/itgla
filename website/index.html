From question to answer

Find it. Check it. Copy it.

Example: a teammate asks where PostgreSQL runs. Find the service, check its host, then copy the address.

  1. Find the service

    Open Services and search by name, tag, host, or version. Each port has its own service record.

  2. Check the context

    Choose View to read the port, protocol, version, contact and notes. Follow connected assets without entering an edit form. Choose Edit only when something needs changing.

  3. Copy what you need

    Use the service record to copy a port or access address. For SSH, copy the SSH command; HTTP and HTTPS addresses open in your browser.

A maintained inventory: you add and update these records. ITGLA does not scan servers, discover services, or verify live DNS.

Common questions

A direct answer before you download.

What is ITGLA?

ITGLA means IT in a glance: a local-first desktop inventory that connects businesses, servers, services and domains. Use records, tags, notes and relationships to keep everyday details clear and prepare for handovers.

Does ITGLA upload server records?

No. The current desktop app stores workspace data in a local SQLite database and does not require an account or cloud sync.

Can I import an existing spreadsheet?

Yes. ITGLA accepts Excel, OpenDocument, CSV, and TSV files and lets you map each source column to a built-in field, suggested field, existing custom field, or a new custom field.

Is ITGLA a server control panel?

No. ITGLA is a manually maintained inventory. It does not scan servers, discover services, verify live DNS, execute commands, deploy services, or replace monitoring and access-control systems.
