Common questions

A direct answer before you download.

What is ITGLA?

ITGLA is a local-first desktop app for recording services, domains, hosting servers, and their connections, alongside server addresses, tags, notes, and custom fields.

Does ITGLA upload server records?

No. The current desktop app stores workspace data in a local SQLite database and does not require an account or cloud sync.

Can I import an existing spreadsheet?

Yes. ITGLA accepts Excel, OpenDocument, CSV, and TSV files and lets you map each source column to a built-in field, suggested field, existing custom field, or a new custom field.

Is ITGLA a server control panel?

No. ITGLA is a manually maintained inventory. It does not scan servers, discover services, verify live DNS, execute commands, deploy services, or replace monitoring and access-control systems.
