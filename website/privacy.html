Privacy Policy

This policy explains how the ITGLA desktop application and itgla.com handle information.

Desktop application data

ITGLA stores server records, tags, IP addresses, ports, custom columns, and application settings in a SQLite database on your device. The current desktop application has no account system, cloud sync, advertising SDK, telemetry SDK, or automatic workspace upload. You control the device, database, imported files, backups, and deletion of that local data.

Website information

When you visit itgla.com, the web server processes the request time, requested path without query parameters, response status, response size, referrer without query parameters or fragments, browser user-agent, and network address. This is used to operate the site, investigate failures, measure aggregate page and download activity, and protect the service.

Identifiers and cookies

The analytics database does not store raw network addresses. A salted one-way value derived from the network address and user-agent is stored to estimate unique visits. The public website does not set analytics or advertising cookies. The protected administrator area uses one strictly necessary session cookie; see the Cookie Policy.

Purpose and legal basis

Where applicable law requires a legal basis, processing is based on the legitimate interests of operating, securing, debugging, and understanding use of this limited website, balanced against data minimization. Information submitted voluntarily through GitHub is processed to respond to the request and is also subject to GitHub's policies.

Retention

Raw web access logs are retained for up to 14 days. Minimized analytics events are retained for up to 365 days. Administrator sessions expire after eight hours and expired session records are deleted. Desktop data remains on your device until you remove it. Backup copies you create remain until you delete them.

Sharing and international processing

ITGLA does not sell personal information. Website infrastructure providers process requests as needed to host and secure the site. GitHub processes repository, issue, and release activity when you use those services. Depending on your location, these providers may process information in other countries under their own safeguards and policies.

Your choices and rights

You can avoid website analytics by not using the website and can obtain releases through GitHub. You can delete desktop data and imported files directly from your device. Depending on your location, you may have rights to access, correct, delete, restrict, object to, or receive a copy of information associated with you. Because website analytics uses minimized pseudonymous identifiers and no account, it may not be possible to reliably identify a particular record without additional information.

Security and sensitive data

Reasonable technical and organizational measures are used, but no system is completely secure. Do not place credentials, private keys, access tokens, or unnecessary personal information in ITGLA records. Do not post real server addresses, credentials, or unredacted database files in a public issue.

Children

ITGLA is a technical infrastructure tool and is not directed to children. Do not use the website to submit information about children.

Changes and contact

Material changes will be dated on this page. For a privacy request, contact the repository owner through the ITGLA GitHub repository. If the request contains sensitive information, first ask for a private contact route and do not place the sensitive material in a public issue.
