隐私说明

这份说明对应 ITGLA v0.1.1 桌面应用与 itgla.com 官网。

桌面数据

ITGLA v0.1.1 将项目、资源、标签和关系保存在你的设备上。应用当前没有账号、云同步、遥测或广告 SDK，也不会主动上传工作区内容。

导入、导出与备份

由你选择的 JSON 导出和 SQLite 备份会写入你指定或应用显示的位置。文件的保存、传输和删除由你控制，请避免在公开位置存放含有基础设施信息的导出文件。

官网访问统计

为了解官网使用情况和排查错误，服务器会记录访问时间、请求路径、响应状态、IP 地址、来源页面和浏览器标识。统计服务使用随机盐将 IP 地址与浏览器标识转换为不可逆的访客标识，统计数据库不保存原始 IP；原始访问日志最多轮转保留 14 天，聚合访问事件最多保留 365 天。官网不使用营销跟踪脚本或第三方分析 Cookie。

第三方服务

源代码、问题反馈和发布记录托管于 GitHub。访问 GitHub 链接时适用 GitHub 自己的隐私政策。

联系与反馈

隐私问题可以通过 GitHub Issues 提交。请勿在公开 Issue 中附上真实服务器地址、凭据或未脱敏的工作区导出。
