Privacy

This notice covers the ITGLA desktop app and itgla.com.

Desktop data

Server records are stored on your device. The app currently has no account, cloud sync, telemetry, advertising SDK, or automatic workspace upload.

Website analytics

The server records request time, path, status, referrer, browser identifier, and IP address for operations and aggregate traffic reporting. A salted one-way visitor identifier is stored instead of the raw IP. Raw access logs are retained for up to 14 days and aggregate events for up to 365 days.

Contact

Use GitHub Issues for privacy questions. Never post real server addresses, credentials, or unredacted database files publicly.
