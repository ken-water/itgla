Workflow guide

A spreadsheet alternative for server inventory

A spreadsheet is often the right starting point. A focused inventory can help when the same server facts are becoming difficult to find, standardize, or copy reliably.

When a spreadsheet is still a good fit

Keep using a spreadsheet if you need simultaneous editing, formulas, pivot tables, broad collaboration, or a custom workflow your team already maintains well. ITGLA is not a collaborative cloud spreadsheet and should not replace a workflow that is working for you.

When a focused inventory may help

Consider a dedicated server inventory when you repeatedly look up IP addresses and ports, need to filter the same records by tags, want a compact table with predictable columns, or copy individual values during routine work.

Move data without rebuilding the sheet

ITGLA can read Excel, OpenDocument, CSV, and TSV files. During import, map the columns you need to IP Address and Ports, use Tags for flexible categories, map to suggested fields such as Project or Cloud Provider, create custom fields, or skip irrelevant columns.

Know the trade-offs

ITGLA is a local desktop tool. Its current version does not provide shared editing, cloud sync, server command execution, deployment, monitoring, or a secrets vault. The workspace is stored locally, so you are responsible for backups and choosing a safe place for the database.
