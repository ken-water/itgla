Privacy model

What local-first means for a server inventory

In ITGLA's current desktop release, your server workspace stays in a local SQLite database on the device where you use the app.

No account or workspace upload

The current desktop application does not require an account, provide cloud synchronization, or automatically upload your server records. Spreadsheet import is also processed locally by the desktop application.

You control storage and backups

Local storage means you choose the device, file access, backup location, and deletion process. Protect the database as you would other infrastructure documentation. Avoid storing credentials or private keys in notes and custom fields.

Local-first is not a security guarantee

Local-first does not make a device immune to malware, theft, unauthorized accounts, or disk failure. Use operating-system protections, encryption and backups appropriate to your environment. ITGLA is an inventory, not a secrets manager or access-control system.

Website analytics are separate

Visiting the ITGLA website is separate from using the desktop app. The website's limited analytics and retention practices are described in the Privacy Policy. Learn about the server inventory workflow or download the desktop app.
