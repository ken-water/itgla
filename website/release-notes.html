Version history

Release notes

Every published ITGLA desktop release, from the first local workspace to the current cross-platform inventory.

v0.5.0 · October 24, 2026

Clearer actions and verified inventory

  • Primary and secondary desktop actions now have distinct visual states, focus feedback, and safer disabled behavior.
  • Appearance previews update the workspace immediately for color, text size, and row spacing; explicit Save settings controls persistence.
  • Settings now gives Status its own input, keeping status and environment drafts independent.
  • Added inventory verification dates, CSV export, and spreadsheet formula protection.
  • Refreshed the official homepage, downloads, release notes, sitemap, and llms.txt.

v0.5.0 · October 24, 2026

Services, domains, and their connections

  • macOS 14+ packages are available for both Apple silicon (arm64) and Intel (x86_64).
  • Record service versions, ports, access addresses, tags, notes, and hosting servers.
  • Track domains, parent hostnames, registrars, registration/expiry dates, CDN targets, and multiple origins.
  • Connect dependencies, replication, failover, and load balancing.
  • Optionally protect service accounts with Windows user-profile encryption, explicit reveal/copy, and a 30-second unlock. Linux/macOS support metadata only; a different Windows profile may require re-entering credentials.
  • Schema 16 creates a pre-upgrade database backup. Use full database backups in Settings; legacy project JSON excludes this inventory. Rolling back requires the older binary and pre-upgrade database, losing later edits.

v0.3.30 · October 18, 2026

Safer imports, flexible fields, and local backups

  • Added managed tag suggestions while preserving fast free-form tags.
  • Added typed custom Server fields for text, numbers, dates, URLs, and booleans.
  • Added explicit duplicate-import policies: create new, skip existing, or update by Server IP and Site URL.
  • Added validated timestamped SQLite backups with configurable retention.
  • Published verified Windows EXE/ZIP, Linux DEB/RPM/AppImage, and macOS arm64 DMG packages.

v0.3.29 · October 18, 2026

Personal settings and a safe Demo workspace

  • Added four curated visual themes, three text sizes, and compact, comfortable, or spacious table density.
  • Added persistent cell-preview and fit-columns-on-open preferences.
  • Added an isolated Demo workspace with realistic fictional Servers, Sites, tags, environments, statuses, and custom fields.
  • Demo edits stay in a separate in-memory database and never modify the real workspace.

v0.3.28 · October 18, 2026

Consistent environments, statuses, Servers, and Sites

  • Added a Settings tab and managed Environment and Status choices with safe defaults.
  • Replaced repeated Environment and Status typing with consistent dropdown editors.
  • Added a complete Sites table with URL, Environment, Status, Purpose, Tags, search, sorting, copying, editing, hiding, and import.
  • Promoted Server Name, Environment, Status, and Purpose to standard fields while preserving custom data and column widths.

v0.2.4 · October 14, 2026

Editable, resizable server tables

  • Double-click a server-table cell to edit and save its value in place.
  • Drag table headers to resize columns, or use Auto to fit visible content.
  • Persisted font-size and column-width preferences in the local SQLite workspace.
  • Stabilized spreadsheet imports with custom columns so the app remains open after import.

v0.2.3 · October 5, 2026

Projects, operations, and persistent planning

  • Published Windows, Linux DEB/RPM/AppImage, and macOS DMG packages.
