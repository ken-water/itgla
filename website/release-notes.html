Version history

Release notes

Every published ITGLA desktop release, from the first local workspace to the current cross-platform inventory.

v0.2.3 · October 5, 2026

Projects, operations, and persistent planning

  • Added Projects and Operations tabs with English countdown fields.
  • Added SQLite schema v6 for project plans, operations, priority options, and media options.
  • Added the native ITGLA logo and enlarged hover previews for dense table fields.
  • Published Windows, Linux DEB/RPM/AppImage, and macOS DMG packages.

v0.2.2 · September 25, 2026

Focused analytics and platform packages

  • Added Overview, Traffic, Downloads, and Errors tabs to the protected analytics dashboard.
  • Added focused trend charts, country-level traffic and download summaries, and filtered normal traffic metrics.
  • Added Windows installer, Linux DEB/RPM/AppImage, and macOS DMG release packages.

v0.2.0 · September 25, 2026

Dense server inventory

  • Added server tags, custom columns, header sorting, and click-to-copy cells.
  • Added Excel, OpenDocument, CSV, and TSV import with per-column mapping.
  • Added persistent custom columns and SQLite schema v5.
  • Replaced Archive with reversible Hide and Restore.

v0.1.1 · September 19, 2026

Portable desktop packaging

  • Added reproducible Windows x86_64 packaging and SHA-256 checksums.
  • Added Windows-native CI and bounded GUI startup validation.
  • Added the official English website and platform download documentation.

v0.1.0 · September 19, 2026

Cross-project resource workspace

  • Added cross-project search, Needs Attention filtering, and result navigation.
  • Added relationship graph navigation and accessible interaction states.
  • Replaced prototype placeholders with local-save and version information.

v0.0.5 · September 19, 2026

Recovery and portability

  • Added SQLite backup, restore, JSON workspace export, and validated import.
  • Added fail-closed schema compatibility checks and recovery documentation.

v0.0.4 · September 19, 2026

Relationship workspace

  • Added project resources, typed relationships, and relationship lifecycle controls.
  • Added graph-focused project navigation and resource health states.

v0.0.3 · September 19, 2026

Resource inventory foundation

  • Added websites, domains, certificates, servers, and services as typed resources.
  • Added project-scoped resource editing and health indicators.

v0.0.2 · September 19, 2026

Local project storage

  • Added the first SQLite-backed project and asset workspace.
  • Added local validation and deterministic project ordering.

v0.0.1 · September 19, 2026

First public desktop build

  • Introduced ITGLA as a local-first IT resource inventory for independent builders.
  • Established the Windows and Linux development and packaging baseline.
