# Gumroad asset package

- `itgla-logo.svg`: scalable brand mark.
- `itgla-cover.svg`: 16:9 product cover source. Export at 1280×720 PNG if SVG upload is rejected.
- `itgla-thumbnail.svg`: square product thumbnail source. Export at 600×600 PNG if SVG upload is rejected.
- `product-copy.md`: exact draft copy and upload checklist for the Gumroad form.

SVG files are editable source assets. Gumroad's cover guidance asks for a horizontal image and its thumbnail guidance asks for a square image. PNG exports are included as a fallback requirement, not generated automatically here.
