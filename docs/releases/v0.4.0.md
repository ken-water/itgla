# ITGLA v0.4.0

Date: 2026-10-24. Release owner: ken-water. Source: Git tag v0.4.0. Artifact digests: release `sha256sums`.

Official website and downloads: https://itgla.com/downloads.html

Adds a small manual Services & Domains inventory linked to existing servers: version/ports/address, tags/notes, Windows-protected service account, directed dependency/replication/failover/balancing, registrar/dates/CDN and multiple origins. No discovery, remote execution or DNS changes.

## Data and platform compatibility

Schema16 adds inventory tables after creating `backups/pre-schema-16.db`. Migration and record writes are transactional. Full database backups preserve inventory and links; legacy project JSON excludes them (the UI warns). Metadata/notes remain unencrypted. Windows CurrentUser DPAPI protects optional username/password; these are masked by default, explicitly revealed/copied, and unlocked for30 seconds. Clipboard clearing is conditional; clipboard history may retain copies. Linux/macOS support metadata, not credential storage. Other Windows accounts/devices may require re-entering credentials. Packages are unsigned/not notarized as before.

Older binaries reject schema16. Rollback requires preserving the current DB separately, then the previous binary plus pre-schema-16.db; later edits are lost. No server-side customer database migration occurs during publishing.
