## Scope

Ship the Free-first desktop workflow: Overview, guided first use, isolated sample data, global asset search, shared asset details, recorded-date reminders with review history, full database backup and confirmed restore, metadata-only handover export, and relationship-map filtering/navigation improvements. Update the official homepage, screenshots, getting-started guide, Free/Pro/Team comparison, release notes, sitemap, and `llms.txt` to describe the same shipped behavior.

Schema 22 adds reminder review and activity tables. Migration 022 is additive and transactional; existing migration code writes `pre-schema-22.db` before applying it. Keep a separate full database backup before upgrading. Full backups contain sensitive data and are not encrypted containers. Metadata handover export omits dedicated credential fields, custom fields, links and notes; names, addresses and contacts can still be sensitive. Reminders recalculate while the application is open and do not send closed-app notifications.
